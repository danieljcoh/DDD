
## Day 9 — “Claim Board” 

### Client scenario
A guild posts “tasks” (bounties, deliveries, scouting runs). Any logged-in guild member can **claim** a task, work it, and then **complete** it. The guild master wants public browsing, but the claim/completion workflow must be safe with multiple users clicking around.

### What the client needs (user stories)
+ As a visitor, I can browse all tasks and view a task detail page.
+ As a logged-in user, I can create a task (authored by me).
+ As a logged-in user, I can **claim** an unclaimed task.
+ As the claimer, I can **unclaim** it (return it to the board).
+ As the claimer, I can mark it **completed**.
+ As any user, I can see a task’s current status: Open / Claimed / Completed, and who claimed it.
